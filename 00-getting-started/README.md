# Lesson 00 — Getting Started

Welcome. Before we write any CSS, let's get your environment set up and understand what's actually happening when you open an HTML file.

---

## What is HTML?

HTML is the **skeleton** of a webpage. It defines what content exists and what it means — a heading, a paragraph, a button, an image.

CSS is the **skin and clothes**. It defines how that content looks.

Browsers read HTML files and render them visually. That's it. There's no app to install, no server needed — just a file on your computer and a browser to open it.

---

## Your First File

Open `hello-world.html` in your browser by double-clicking it (or dragging it into Chrome/Firefox).

Then open the same file in VS Code.

You'll see the code on the left and the result in the browser. Change something — anything — save it (`Cmd+S` / `Ctrl+S`), and refresh the browser. That feedback loop is how you'll learn everything in this course.

---

## VS Code Live Preview (Optional but Recommended)

Instead of manually refreshing, install the **Live Preview** extension:

1. Open VS Code
2. Click the Extensions icon in the sidebar (or `Cmd+Shift+X`)
3. Search "Live Preview" by Microsoft
4. Install it
5. Open any `.html` file and click the preview icon in the top-right

Now the browser preview updates as you type. Much better.

---

## What to Notice in the File

When you open `hello-world.html`, look at:

- The overall **shape** of the file — things open and close
- How indentation shows **nesting** — some things live inside others
- How `<style>` lets CSS live inside an HTML file
- How changing a number in CSS immediately changes the visual result
