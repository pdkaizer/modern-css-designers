# Contributing

Thank you for helping improve this course! Contributions are welcome.

---

## What to Contribute

- **Bug fixes** — broken code in a starter or solution file
- **Clarifications** — README explanations that confused you
- **New exercises** — additional challenges within existing lessons
- **Accessibility improvements** — better `alt` text, ARIA patterns, semantic HTML
- **Browser compatibility notes** — flag anything that needs a caveat

---

## What's Out of Scope

- New lessons — the course scope is fixed
- Adding build tools or JavaScript — this course deliberately uses none
- Framework-specific patterns (React, Vue, etc.)

---

## How to Contribute

1. Fork the repository
2. Create a branch: `git checkout -b fix/lesson-03-typo`
3. Make your change
4. Test it — open the HTML file in Chrome and Firefox and verify it works
5. Open a pull request with a clear description of what you changed and why

---

## Style Guidelines

- Match the existing tone — conversational, designer-friendly, no jargon without explanation
- One concept at a time — don't introduce a new concept while explaining another
- Show before-and-after comparisons where possible
- Comments in code should explain *why*, not *what*
- All CSS in starter and solution files should reference custom property tokens — no hard-coded values

---

## Code of Conduct

Be kind. This course is written for beginners; every question is a valid question.
