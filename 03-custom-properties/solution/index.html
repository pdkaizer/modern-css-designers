Design Tokens in CSS

Custom properties let you define values once and use them everywhere — exactly like styles in Figma. Change a token, everything updates.

Foundations

What are design tokens?

Design tokens are the atomic decisions of a design system — colors, spacing, type scales, border radii. When stored as CSS custom properties, they're instantly shareable between components.

Tutorial

How to use var()

Once you've defined --color-brand in :root, you use it as color: var(--color-brand). If the variable isn't found, you can provide a fallback: var(--color-brand, blue).
